BETA 2 FEATURE STATUS

Available in the tested Windows 0.3.1 Beta 2:
- Numeric manual pitch timeline, 64 regions; not a graphical piano roll.
- Momentary, short-term and gated integrated output LUFS, reset control.
- Windows offline stem companion; synthetic-audio inference test passed.
- All previous Beta 1 processing, presets and UI features.

Shared source includes pitch edits and LUFS for the Mac AU.
Mac release requires remote compilation, signing checks, Apple auval and
plugin host tests. The current Mac build is still pending validation.
The workflow attaches the AU ZIP to the Beta 2 release only after passing.

Stem processing runs on Windows. Transfer the four finished WAVs to Mac.
There is no in-plugin realtime AI separation engine and no Mac AI install.

Still absent: graphical piano-roll editor, signed retail installers,
Apple notarization, automatic updates, and enforced 25-person activation.
Private GitHub access restricts downloads, not copied plugin execution.
Musical separation quality and cross-DAW listening tests remain necessary.
